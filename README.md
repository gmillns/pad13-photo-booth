# Pad 13 Photo Booth

Android photo booth for the OSCAL Pad 13.

## v0.1
- Landscape full-screen camera
- Front camera preferred automatically
- 3-2-1 countdown
- Retake / Keep Photo review
- Saves accepted JPEGs to **Pictures/LadiesNightPhotoBooth**
- Thank-you screen and automatic reset
- No internet required while using the booth

## Build the APK with GitHub Actions
1. Upload the contents of this project to the root of your `pad13-photo-booth` repository.
2. Open the repository's **Actions** tab.
3. Open **Build Android APK**.
4. Open the latest successful run.
5. Under **Artifacts**, download **Pad13-Photo-Booth-v0.1**.
6. Unzip the downloaded artifact on the Pad 13 and tap `app-debug.apk` to install it.

The first time Android may ask permission to install unknown apps from your browser/files app. The app itself will ask for camera permission on first launch.
